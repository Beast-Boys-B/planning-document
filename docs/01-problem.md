# 문제 정의 — Yahoo_Prompt (AI 프롬프트 작성 도우미)

> :warning: 아래 "팀 아이디어 선택 기록"의 평가 기준은 원본 예시(팀 일정 관리)의 기준을 그대로 쓰지 않고, 실제로 이 프로젝트에서 사용한 의사결정 기준으로 바꿔서 채웠습니다. "유사 서비스" 표는 웹 검색 기반으로 채운 초안이라, 팀원이 직접 서비스에 접속해 확인 후 보완이 필요합니다.

| 후보 | ① 실제 사용 장면 있음 | ② 구현 안정성 | ③ 비전공자도 바로 사용 가능 | 결과 |
|---|---|---|---|---|
| A안 — 규칙 기반 신호 추출 (자연어 → 키워드 매칭 → 템플릿 매핑) | O — 사용자가 편하게 쓴 문장에서 톤·길이·목적 등을 뽑아 프롬프트로 정리 | O — LLM 미탑재, 정해진 값 분류라 오탐 관리가 쉬움 | O — 자동 감지 결과를 눈으로 확인·수정 가능 | **선택** |
| B안 — LLM 기반 자유 슬롯 완전 자동화 (자연어를 LLM이 통째로 분해) | O | X — 자유 슬롯 파싱은 오탐 위험이 크고 개발 난이도가 현재 진행 여건에 비해 과함 | O (이론상 표현력은 더 높음) | 탈락 (구현 안정성에서 밀림) |
| 프롬프트 학습 콘텐츠 제공형 (가이드·강의 형태) | X — 사용자가 여전히 직접 학습해야 하는 부담이 그대로 남음 | O | X — 학습에 드는 진입장벽이 해소되지 않음 | 탈락 |

## 4요소

| 칸 | 내용 |
|---|---|
| **문제** | 코딩 등 전문 영역 사용자는 프롬프트 엔지니어링 지식이나 에이전트 도구로 프롬프트를 정교하게 다듬어 원하는 결과를 뽑아내지만, **대부분의 일반 AI 사용자는 그런 보정 수단 없이 그때그때 떠오르는 말을 그대로 자연어로 입력**한다. 그 결과 "입력한 프롬프트"와 "원하는 결과값" 사이에 구조적인 괴리가 생긴다. 이 괴리는 AI 사용자층이 다양한 연령대로 늘어날수록, 특히 **40대 이상 고령층**에서 더 두드러질 것으로 예상된다 |
| **대상** | ChatGPT·Gemini 등 **범용 AI를 업무·일상에 활용하려는 비전공자**, 특히 40대 이상 |
| **현재해법** | (1) 원하는 답이 나올 때까지 AI와 계속 씨름하기 (2) 본인이 프롬프트 엔지니어링을 따로 공부해서 활용하기 |
| **불편** | 정해진 요령 없이 시행착오를 반복하며 시간을 쓰거나, 프롬프트 학습에 별도 리소스를 들여야 함 (구체적인 소요 시간·반복 횟수는 수치화된 근거 없음 — 확인 필요) |

## 한 문단으로

코딩 등 전문 영역에서는 프롬프트 엔지니어링 지식이나 에이전트 도구가 사용자의 의도와 AI의 결과물 사이 간극을 메워주지만, 대부분의 일반 AI 사용자는 그런 보정 수단 없이 떠오르는 말을 그대로 자연어로 입력해 원하는 산출물을 얻지 못하는 경우가 많다. 현재로선 원하는 답이 나올 때까지 AI와 계속 씨름하거나 프롬프트 엔지니어링을 따로 공부하는 수밖에 없는데, 두 방법 모두 비전공자, 특히 40대 이상 고령층에게는 진입장벽이 높다. Yahoo_Prompt는 사용자가 자연어로 편하게 입력하면 규칙 기반으로 신호를 추출해, AI가 더 잘 알아듣는 프롬프트로 자동 정리해주는 도구다.

## 확인할 수 없어 표시해 둔 것

- 위 유사 서비스 3개의 기능 범위는 검색 스니펫 기준이라, 실제 UI·동작 방식은 팀원이 직접 설치·접속해서 재확인 필요
- "구현 안정성" 기준으로 B안(LLM 기반)을 탈락시킨 판단 — 실제 프로토타입으로 오탐률을 비교 측정한 것은 아니고, 팀 논의 중 도출된 판단임

### 참고 — 문제 정의의 근거 성격

"일반 사용자가 원하는 결과를 못 뽑아낸다"는 명제는 **몇 %가 겪는 문제인지로 증명하는 통계형 근거가 아니라, 코딩 등 전문 영역과 일반 사용 사이의 구조적 차이에서 나오는 논리형 근거**다. 즉 전문 영역엔 프롬프트 엔지니어링 지식·에이전트라는 "보정 수단"이 있고 일반 사용자에겐 없다는 비대칭 자체가 항상 성립하므로, 별도의 발생 빈도 조사 없이도 문제 정의로 유효하다.

다만 "특히 고령층에서 두드러질 것"이라는 부분은 정도의 문제라 참고 데이터를 붙여둔다. KISDI(2025)와 KDI 조사에 따르면 생성형 AI·AI챗봇 인지도·이용률은 연령이 높을수록 뚜렷하게 낮아진다(예: '아는 편이다' 이상 응답 30대 75.8% vs 60대 22.6%, 70대 7.2%; 이용률 30대 26.5% vs 50대 8.5%, 60대 3.4%). 이는 "프롬프트 작성 난이도"를 직접 측정한 수치는 아니고 "인지도·이용률" 지표이지만, 고령층일수록 AI 활용에 더 큰 진입장벽을 겪고 있음을 보여주는 간접 근거로 볼 수 있다.
