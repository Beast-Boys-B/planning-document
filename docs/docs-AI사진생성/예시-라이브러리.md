#인물
**사람**을 중심으로 한 **현실적** 이미지를 만들어줘. 배경보다는 인물이 돋보이도록 **클로즈업**해서 표현해줘.
스타일: 사진 같은 현실적 / 피사체: 인물 중심 / 구도: 클로즈업

- **사람** → 축 2 주요 피사체: 인물 중심
- **포토리얼** → 축 1 스타일: 사진 같은 현실적
- **클로즈업** → 축 3 구도/프레이밍: 클로즈업

#풍경
제주도의 **바다**와 자연이 보이는 **사진**을 만들어줘. 해안과 하늘이 한눈에 들어오도록 **광각**으로 표현해줘.
스타일: 사진 같은 현실적 / 피사체: 인물 중심 아님 / 구도: 광활한 뷰

- **바다** → 축 2 주요 피사체: 인물 중심 아님
- **사진** → 축 1 스타일: 사진 같은 현실적
- **광각** → 축 3 구도/프레이밍: 광활한 뷰

#음식

#동물
귀여운 **고양이**가 창가에 앉아 있는 모습을 **카툰** 느낌으로 만들어줘. 고양이가 크게 보이도록 **가까운** 구도로 표현해줘.
스타일: 일러스트,만화,추상적 / 피사체: 인물 중심 아님 / 구도: 클로즈업

#건축

스타일: 사진 같은 현실적 / 피사체: 인물 중심 아님 / 구도: 광활한 뷰

- **건물**, **도시** → 축 2 주요 피사체: 인물 중심 아님
- **3D 렌더링** → 축 1 스타일: 사진 같은 현실적
- **와이드 샷** → 축 3 구도/프레이밍: 광활한 뷰
