## 상태값
목적·대상·문서유형·긴급도 4개 축은 자연어 입력 1회(공통 F-공3·F-공12 신호 추출 시점)에 서로 독립적으로 동시에 확정된다. 이 중 문서유형=체계적 형식(우)이면 P-작1이 적용되는 상태로, 대상=상급자·외부인(좌)이면 P-작2가 적용되는 상태로 각각 전이한다. 두 조건은 서로 다른 축이므로 독립적으로 동시에 적용될 수 있다(예: 문서유형=체계적 형식 AND 대상=상급자·외부인이면 P-작1·P-작2 모두 적용). 목적·긴급도 축에는 조건부 고정 규칙이 없어 별도 상태 전이가 없다.
