# AI 사진생성

- **출력 형식**: 태그나열형 (`[사용자 원문], tag1, tag2, ...` 방식으로 조립)
- **담당**: 담당자 조연익

## 전용 축

### 축 1 — 용도
- 좌: 개인용(개인 보관/SNS) / 우: 상업용(마케팅/판매/공식 자료)
- 좌 신호 키워드: 개인용, SNS, 인스타그램, 개인 블로그, 혼자 보려고, 저장해두려고, 재미로, 취미
- 우 신호 키워드: 광고, 마케팅, 판매, 상업용, 회사, 제품 홍보, 공식, 웹사이트, 포스터, 카탈로그
- 기본값: 좌 (개인용)

### 축 2 — 스타일
- 좌: 사진 같은 현실적 / 우: 일러스트/만화/추상적
- 좌 신호 키워드: 사진, 현실적, 포토리얼, 실제처럼, 진짜 사진, 3D 렌더링, 사실적
- 우 신호 키워드: 일러스트, 만화, 카툰, 그림, 손그림, 추상적, 판타지, 컨셉아트, 스타일라이즈
- 기본값: 좌 (사진 같은 현실적)

### 축 3 — 주요 피사체
- 좌: 인물 / 우: 인물 제외(풍경/물건/동물)
- 좌 신호 키워드: 사람, 인물, 여자, 남자, 아이, 얼굴, 사진, 초상화, 포즈
- 우 신호 키워드: 풍경, 자연, 건물, 물건, 제품, 동물, 배경, 숲, 바다, 도시
- 기본값: 우 (인물 제외)

### 축 4 — 구도/프레이밍
- 좌: 클로즈업(얼굴/세부 중심) / 우: 광활한 뷰(전체 샷/풍경)
- 좌 신호 키워드: 클로즈업, 가까운, 확대, 얼굴, 세부, 근접, 초상화, 헤드샷
- 우 신호 키워드: 멀리서, 광각, 전체 샷, 풍경, 배경 포함, 전경, 넓게, 드넓은
- 기본값: 우 (광활한 뷰)

## 고정 규칙

```
고정_규칙: [
  { 조건: "용도=상업용", 문구: "생성된 이미지는 상업적 이용 전 해당 AI 서비스의 이용 약관과 저작권 정책을 확인하세요." },
  { 조건: "주요_피사체=인물", 문구: "더 정확한 결과를 위해 인물의 나이대, 성별, 표정, 스타일을 함께 적어주시면 좋아요." }
]
```

## 겹침 처리 규칙

한 축 내에서 좌/우 신호가 동시에 감지되면, 문장에서 더 나중에 등장한 신호를 우선 채택.

## 참고 — 다른 카테고리와의 조립 방식 차이

다른 4개 카테고리(역할지정형)는 "당신은 ~입니다. ~해주세요" 문장으로 조립되지만, 이 카테고리는 `[사용자 원문], 태그1, 태그2, ...` 형태로 조립됩니다. 결과 확인 화면에서도 이 카테고리에 한해 "이미지 생성 AI(Midjourney, DALL·E, Gemini 이미지 생성 등)에 붙여넣으세요"로 안내 문구가 달라집니다.
