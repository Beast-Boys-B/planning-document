# 의료질문/문진

- **출력 형식**: 역할지정형
- **담당**: 담당자 우석민

## 전용 축

### 축 1 — 목적
- 좌: 증상·질병 정보 알아보기 / 우: 병원 가기 전 문진 준비하기
- 좌 신호 키워드: 증상, 왜 그런지, 원인이 뭔지, 이게 무슨 병, 병명, ~인가요, 위험한가요, 심각한가요, 이 정도면 괜찮은지, ~때문인지
- 우 신호 키워드: 병원 가기 전, 의사한테 뭐라고, 진료 볼 때, 물어볼 거, 준비해야 할 거, 문진표, 예약했는데, 검사받으러 가는데, 상담받기 전에
- 기본값: 좌 (증상·질병 정보 알아보기)

> AI 역할(페르소나)은 이 축에서 결정됩니다. 좌: 건강 정보를 알기 쉽게 설명해주는 안내자 / 우: 진료 전 준비를 돕는 코디네이터.

### 축 2 — 대상
- 좌: 본인 / 우: 가족/보호 대상자
- 좌 신호 키워드: 제가, 저는, 나는, 요즘 제가, (주어 없이 본인 지칭)
- 우 신호 키워드: 엄마가/어머니가, 아빠가/아버지가, 아이가/아들이/딸이, 남편이/아내가, 할머니가/할아버지가, 부모님이, 신생아, 영유아, 우리 애가
- 기본값: 좌 (본인)

### 축 3 — 증상 성격
- 좌: 갑자기 생긴 증상 / 우: 오래된/만성 증상
- 좌 신호 키워드: 갑자기, 어제부터, 오늘부터, 방금, 급격히, 순간적으로
- 우 신호 키워드: 계속, 오래전부터, 몇 달째, 몇 년째, 만성, 반복적으로, 예전부터, 자꾸 재발
- 기본값: 좌 (갑자기 생긴 증상)

## 고정 규칙

```
고정_규칙: [
  { 조건: "항상", 문구: "이 정보는 진단을 대체하지 않으며, 응급 증상은 즉시 119/응급실로 문의하세요." }
]
```

## 겹침 처리 규칙

한 축 내에서 좌/우 신호가 동시에 감지되면, 문장에서 더 나중에 등장한 신호를 우선 채택.
