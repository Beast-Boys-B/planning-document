# 작성

- **출력 형식**: 역할지정형
- **담당**: 담당자 조연익

## 전용 축

### 축 1 — 목적
- 좌: 정보 전달/보고하기 / 우: 요청/승인받기
- 좌 신호 키워드: 보고, 전달, 공유, 알려드립니다, 완료, 결과, 현황, 진행 상황, 공지
- 우 신호 키워드: 요청, 승인해 주세요, 검토 부탁, 결재, 허락받고 싶은데, ~해주실 수 있을까요, 도와주세요, 협조 부탁
- 기본값: 좌 (정보 전달/보고하기)

### 축 2 — 대상
- 좌: 상급자/외부인 / 우: 동료/팀원
- 좌 신호 키워드: 사장님, 임원진, 본부장, 과장/팀장 이상, 거래처, 외부, 고객, 클라이언트, 상사
- 우 신호 키워드: 팀원, 동료, 같은 팀, 우리 팀, 후배, 옆 부서, 같은 직급, 형/누나/언니/오빠
- 기본값: 좌 (상급자/외부인)

### 축 3 — 문서 유형
- 좌: 간단한 형식(이메일/메신저) / 우: 체계적 형식(회의록/보고서/기획서)
- 좌 신호 키워드: 이메일, 메시지, 메신저, 카톡, 슬랙, 한두 줄, 빠르게, 간단히
- 우 신호 키워드: 회의록, 보고서, 기획서, 제안서, 문서, 형식적, 체계적, 상세하게, 첨부
- 기본값: 좌 (간단한 형식)

## 고정 규칙

```
고정_규칙: [
  { 조건: "상급자, 외부인", 문구: "공손한 말투: 상사나 고객에게 적합한 존댓말을 사용해요." }
]
```

## 겹침 처리 규칙

한 축 내에서 좌/우 신호가 동시에 감지되면, 문장에서 더 나중에 등장한 신호를 우선 채택.
