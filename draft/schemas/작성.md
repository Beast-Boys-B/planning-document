# 작성

- **출력 형식**: 역할지정형
- **담당**: 담당자 조연익

## 전용 축

### 축 1 — 목적
- 좌: 정보 전달/보고하기 / 우: 요청/승인받기
- 좌 신호 키워드: 보고, 전달, 공유, 알려드립니다, 완료, 결과, 현황, 진행 상황, 공지
- 우 신호 키워드: 요청, 승인해 주세요, 검토 부탁, 결재, 허락받고 싶은데, ~해주실 수 있을까요, 도와주세요, 협조 부탁
- 기본값: 좌 (정보 전달/보고하기)

### 축 2 — 대상
- 좌: 상급자/외부인 / 우: 동료/팀원
- 좌 신호 키워드: 사장님, 임원진, 본부장, 과장/팀장 이상, 거래처, 외부, 고객, 클라이언트, 상사
- 우 신호 키워드: 팀원, 동료, 같은 팀, 우리 팀, 후배, 옆 부서, 같은 직급, 형/누나/언니/오빠
- 기본값: 좌 (상급자/외부인)

### 축 3 — 문서 유형
- 좌: 간단한 형식(이메일/메신저) / 우: 체계적 형식(회의록/보고서/기획서)
- 좌 신호 키워드: 이메일, 메시지, 메신저, 카톡, 슬랙, 한두 줄, 빠르게, 간단히
- 우 신호 키워드: 회의록, 보고서, 기획서, 제안서, 문서, 형식적으로, 체계적으로, 상세하게, 첨부
- 기본값: 좌 (간단한 형식)

### 축 4 — 긴급도
- 좌: 일반적 / 우: 긴급
- 좌 신호 키워드: 일반적으로, 보통, 시간 있을 때, 언제든, 오늘/내일
- 우 신호 키워드: 긴급, 급하게, 지금 당장, 2시간 이내, 오늘 중에, 즉시, ASAP, 급함
- 기본값: 좌 (일반적)

## 고정 규칙

```
고정_규칙: [
  { 조건: "문서_유형=체계적_형식", 문구: "구조화된 템플릿 형식(항목별 소제목, 번호 매기기)으로 제공" },
  { 조건: "대상=상급자_외부인", 문구: "존댓말과 공손한 표현 사용" }
]
```

## 겹침 처리 규칙

한 축 내에서 좌/우 신호가 동시에 감지되면, 문장에서 더 나중에 등장한 신호를 우선 채택.
