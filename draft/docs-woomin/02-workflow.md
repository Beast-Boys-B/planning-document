## 행위자
| A | 이름 | 역할 | 한 줄 상황 | 지금 쓰는 도구 |
|---|---|---|---|---|
| A1 | 사용자 | AI 지식이 없거나 사용 경험이 적어 만족스러운 사용감을 얻지 못하는 경우 모두 (예: 직장인, 자영업자, 주부, 비전공 학생 등) | AI를 어느 목적성을 가지고 쓰기보다 단순 과제나 궁금증이 생겼을 때도 사용하고, 개인상담이나 의료분야 질문 등의 목적으로 쓰는 경우도 있는데, 이때 자연어로 입력된 프롬프트가 사용자가 원하는 대답을 뱉을 확률보다 프롬프트 엔지니어링 기술을 사용자의 자연어 입력을 필터링해 뱉어주는 느낌으로 구동하게 하려고 함 | AI 도구 |
| A2 | 서비스 운영자/개발자 | 규칙 기반 신호 추출·키워드 매칭 로직을 만들고 오탐을 관리하는 사람 | 사용자 오탐·미탐 피드백을 받아 규칙을 개선함 | 깃허브 |

## 단계 (As-Is → To-Be)
| S | 단계 | 행동(As-Is) | 감정 | 불편 | To-Be 한 줄 |
|---|---|---|---|---|---|
| S0 | 질문거리 정리 전 | 무엇을 물어야 할지조차 명확하지 않은 채로 막연히 AI를 켬 | 막막함, 답답함 | 궁금한 것 자체가 언어화 안 된 상태라 무엇부터 입력해야 할지 모름 | 카테고리를 고르는 것만으로도 "이런 걸 물어보면 돼요" 식 예시(placeholder)가 방향을 잡아줘서, 질문거리가 없어도 일단 시작할 수 있음 |
| S1 | AI 접속 | AI를 사용하여 원하는 답변을 얻기위해 대화형 ai (chatgpt든 제미니든 어느 회사의 것인지는 따지지않음)을 연다 | 없음 | 궁금한것, 질문내용을 사용자가 잘 정제하고 언어화해서 프롬프트에 입력해야함 | 떠오르는대로 편하게 자연어로 입력하기만 하면 됨 |
| S2 | 프롬프트 입력 | 사용자가 정제되지않은 프롬프트를 입력함 | ai가 사용자의 의도를 잘 알아들었을까 느끼는 불안 | 원하는 답변과 다른 방향의 답변이 나올경우 사용자가 프롬프트를 다시 재고해야함 | 신호·키워드 기반으로 정제된 프롬프트가 만들어짐 |
| S3 | 응답확인 | AI가 내놓은 응답을 확인한다 | 이게 맞나 아닌가 헷갈림 | 뭐가 잘못됐는지 콕 집어 말하기 어려움 | 정제된 프롬프트 덕분에 답변이 원하는 방향에 가까워서, 확인이 "찜찜한 재검토"가 아니라 "가벼운 확인"으로 끝남 |
| S4 | 응답 판단 | 만족하면 종료(결과물을 그대로 사용), 불만족하면 S2로 회귀(프롬프트를 고쳐서 다시 입력) | 애매함, 헷갈림, 답답함 | 뭐가 잘못됐는지 구체적으로 짚어내기 어려워 다음에 뭘 고쳐야 할지 감이 안 잡힘 | 처음부터 의도가 반영된 프롬프트라 어긋나는 폭이 작아, 판단이 빠르고 확신을 갖고 다음 행동을 결정할 수 있음 |
| S5 | 프롬프트 재입력 | 반복 끝의 결말: (a) 결국 만족스러운 답을 얻어내거나, (b) 지쳐서 타협한 결과물로 그냥 쓰거나, (c) 아예 포기하는 세 갈래 중 하나로 귀결 | 지침, 짜증, 시간 낭비에 대한 스트레스 | 뭘 어떻게 고쳐야 원하는 방향에 가까워지는지 몰라 감으로 시행착오를 반복함 | 재입력이 필요해도 어떤 설정(톤·길이·축)만 바꾸면 되는지 토글로 바로 보이니, 감으로 헤매지 않고 빠르게 재조정 가능 |
| S6 | 포기 후 대안 탐색 | (c) 포기 이후 A1 이 지인에게 물어보기·검색엔진·전문가 상담 등 다른 수단으로 전환 | 허탈함, 시간 버렸다는 자책 | 처음부터 다른 수단을 썼으면 안 들었을 시간을 AI 씨름에 썼다는 아쉬움 | 재입력 루프(S4↔S5)에서 훨씬 빠르게 만족스러운 답에 도달해, 애초에 포기하고 다른 수단을 찾아 나서는 단계 자체가 크게 줄어듦 |

## 흐름
S1 → S2 → S3 → S4 → (만족: 종료 / 불만족: S5 로 진행) → S5(프롬프트 재입력, S2 로 회귀, 여러 번 반복) → 반복 끝 abc 결말((a) 결국 만족스러운 답을 얻어냄 / (b) 지쳐서 타협한 결과물로 그냥 씀 / (c) 아예 포기) · 분기: S4 에서 만족·불만족으로 갈리고, 불만족은 S5(재입력)→S2 로 이어지는 루프를 형성하며, 이 루프가 반복되다 abc 세 갈래 중 하나로 귀결
