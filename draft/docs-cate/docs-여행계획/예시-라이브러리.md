# 예시 문장
- 국내여행 : 단풍보러 갈건데 국내에서 어디가 단풍으로 유명할까?
- 해외여행 : 이번에 처음으로 해외로 여행을 가보려고 해. 가볼만한 여행지 3군데 정도 추천해줘.
- 혼자여행 : 친구나 가족들과만 여행 했었는데 이번에는 혼자 여행을 떠나보려 해. 걱정되는데 도움을 줬으면 좋겠어.
- 음식추천 : 이번에 오사카로 놀러가는데 그 지역만의 음식을 먹고 싶어. 어떤 음식이   있는지 알려주고 맛있게 잘하는 가게를 추천해줘
- 환율 : 곧 미국으로 여행을 떠나는데 현재 환율이 궁금해. 오늘 기준으로 환율을 알려줬으면 좋겠어.
- 숙소검색 : 영국으로 3명이서 5박 6일 여행을 계획하고 있어. 런던에 숙소를 잡고 싶은데 가성비 좋은 숙소를 검색해줘.
- 예산 편성 : 이번에 도쿄 여행을 3박 4일로 나 혼자 갈거야. 비행기값, 숙소, 교통비, 식사 포함해서 보통 얼마 정도 나오는지 궁금해.
