#인물
인스타그램에 올릴 현실적인 여자 인물 사진을 만들어줘. 얼굴이 잘 보이도록 클로즈업으로 찍은 느낌이면 좋겠어.

#풍경
개인 블로그에 올릴 제주도 바다 풍경을 진짜 사진처럼 만들어줘. 해안과 하늘이 모두 보이도록 넓게 보여줘.

#음식
식당 광고에 사용할 스테이크 제품 사진을 포토리얼하게 만들어줘. 고기의 질감과 육즙이 보이도록 가까운 구도로 보여줘.

#동물
SNS에 올릴 귀여운 고양이 동물 이미지를 카툰 느낌으로 만들어줘. 고양이 얼굴이 크게 보이도록 클로즈업해줘.

#건축
건축회사 웹사이트에 사용할 현대적인 건물 이미지를 3D 렌더링으로 만들어줘. 건물 전체와 주변 도시가 보이도록 광각으로 표현해줘.

#판타지
게임 마케팅에 사용할 용이 날아다니는 판타지 컨셉아트를 만들어줘. 거대한 성과 숲까지 드넓게 보이는 장면이면 좋겠어.
