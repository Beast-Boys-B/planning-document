## 참고 — 공통 문서와의 관계

- R-사진1·R-사진3·R-사진4·R-사진6(신호 자동 인식)은 개념적으로 `draft/docs-공통/03-requirements.md`의 R-공1·R-공2(자동 정제)와 같은 계열이나, 이 카테고리는 축이 4개(용도/스타일/피사체/구도)라는 점이 고유하다.
- R-사진7·R-사진8은 이 카테고리에서만 발생하는 요구다 — 다른 4개 카테고리는 "역할지정형" 문장으로 결과를 받으므로 해당 요구가 없다. 04-features.md의 "F-공3·F-공4 예외 처리" 절에서 이어서 다룬다.
