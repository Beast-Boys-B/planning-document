> **[팀 결정] 연령대는 "선택 축"이 아니다**: 연령대 추정은 축1~축3처럼 사용자에게 노출되는 선택지·토글이 아니다. 사용자가 직접 고르는 게 아니라, 문장 속 신호(예: "고3", "취준생", "애 엄마")로만 배경에서 자동으로 추정되는 보조 정보다.

## P-상담6 상세 — 축1 다중 감지 시 우선순위 계산 (이재성 정의, `draft/docs-hibro/solution1.md` 참고 — 원문 그대로 옮기되 "동점이면 되묻는다" 부분은 이번엔 반영하지 않음)

### 1단계 — 연령대 추정 (선택 축 아님, 배경 자동 감지)
아래와 같은 명시적 신호로 사용자의 연령대를 판별한다. **연령대는 축1~축3처럼 사용자가 직접 고르는 축이 아니라, 문장 속 신호로만 자동 추정되는 보조 정보다.**
- 예: "고3", "대학생", "취준생", "저 OO살", "직장 N년차", "애 엄마·아빠"
- **신호가 있으면(연령대 파악됨)** → 2~5단계 계산을 진행한다.
- **신호가 없으면(연령대 추정 불가)** → 이 P-상담6 알고리즘 전체를 적용하지 않고, **공통 P-공22(나중에 등장한 신호 우선)를 그대로 따른다.** (2~5단계 계산 자체를 하지 않음)

### 2단계 — 주제별 기본 점수
메시지 안에서 각 주제 키워드가 등장한 횟수 1회당 **+1점**을 부여한다.

### 3단계 — 최근성 가중치
메시지를 문장 단위로 나눴을 때, **가장 마지막 문장**에 등장한 주제에 **+2점**을 부여한다.

### 4단계 — 연령대 가중치
연령대가 파악된 경우에만 아래 표의 값을 더한다.

| 연령대 | 연애 | 인간관계 | 학업 | 진로 | 가족 | 자존감 |
|---|---|---|---|---|---|---|
| 10대 | +1 | +2 | +3 | 0 | 0 | +1 |
| 20대 | +3 | +1 | 0 | +2 | 0 | +1 |
| 30대 | +1 | 0 | 0 | +3 | +1 | +1 |
| 40대 | 0 | +1 | 0 | +1 | +3 | +1 |
| 50대 이상 | 0 | +1 | 0 | 0 | +2 | +3 |

### 5단계 — 최종 점수 계산 및 채택
```
최종 점수 = 기본 점수(2단계) + 최근성 가중치(3단계) + 연령대 가중치(4단계)
```
(이 5단계는 1단계에서 연령대가 파악된 경우에만 진행한다 — 연령대 추정 불가 시에는 이 계산 자체를 하지 않고 공통 P-공22를 따른다.)
- 최고점 주제를 축1의 최종 페르소나로 채택한다.
- 동점일 경우, 최근성(3단계에서 가산을 받았는지 여부)이 높은 쪽을 우선한다.
- **그래도(연령대 파악 + 가중치 계산 후) 완전히 동점인 경우 — 확정**: 문장에서 나중에 등장한 키워드의 주제를 채택한다(공통 P-공22와 동일한 타이브레이커). 원문(solution1.md)의 "사용자에게 되묻는다"는 처리는 반영하지 않는다 — 사용자가 이후 옵션 조정 화면(F-상담1 축1 재선택 등)에서 언제든 다시 바꿀 수 있으므로, 이 이상의 정교한 처리는 불필요하다는 팀 판단.
