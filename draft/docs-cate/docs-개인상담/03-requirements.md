## 참고 — 공통 문서와의 관계
- R-상담1·R-상담2는 개념적으로 `draft/docs-공통/03-requirements.md`의 R-공1·R-공2(자동 정제)와 같은 계열이나, 이 카테고리 고유의 축(상담 주제별 페르소나 6택·상담 스타일 3택·개입 방식 2택)에서 나온 요구라 이 문서에 남겼다.
- R-상담3(톤 재요청)은 `draft/docs-공통`의 R-공4(톤·길이·축 토글 조정)와 같은 메커니즘을 이 카테고리 맥락(상담 스타일 축)에서 쓴 것으로 보인다.
- **R-상담4는 공통 정책 P-공22(겹침 처리 규칙 — 같은 축 내 다중 신호 시 "나중에 등장한 신호 우선")의 개인상담 축1 전용 예외이되, 조건부다.** 연령대가 파악된 경우에만 P-공22 대신 이 카테고리 전용 다단계 점수 계산 규칙(05-policy.md P-상담6)이 우선 적용되고, 연령대를 전혀 못 잡으면(추정 불가) 축1도 그대로 공통 P-공22를 따른다.
