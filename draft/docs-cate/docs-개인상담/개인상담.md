# 프롬프트 라이브러리 예시 — 개인상담

## 해시태그 목록

## 예시 (해시태그별)

### #연애
- 문장: "남자친구랑 요즘 연락이 뜸해졌는데 왜 이러는지 모르겠어서 혼란스러워. 이러다 진짜 이별로 가는 건 아닌지 불안해"
- 감지: 축1=연애(연애고수 모드, "남자친구"·"이별") / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

### #인간관계
- 문장: "친구가 자꾸 나만 빼고 약속 잡는 것 같아서 거리를 두고 싶어지는데, 나를 왜 자꾸 피하는지 잘 모르겠어"
- 감지: 축1=인간관계(친구 상담 모드, "친구가"·"거리를 두고 싶어") / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

### #학업
- 문장: "이번 시험 성적이 너무 안 나와서 공부 방법을 바꿔야 할 것 같은데, 학교 과제까지 겹치니까 뭐부터 해야 할지 모르겠어요"
- 감지: 축1=학업(친한 선생님 모드, "시험"·"성적"·"공부"·"과제"·"학교") / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

### #진로
- 문장: "취업 준비하면서 이직도 고민 중인데 면접 볼 때마다 제 진로가 맞는 건지 자신이 없어져요"
- 감지: 축1=진로(진로 선생님 모드, "취업"·"이직"·"진로"·"면접") / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

### #가족
- 문장: "엄마가 아빠랑 매일 싸우셔서 집에 있기 힘든데, 형이랑 동생이는 신경도 안 쓰는 것 같아 저만 가족 걱정하는 것 같아요"
- 감지: 축1=가족(나이 많은 누나·언니 모드, "엄마가"·"가족" — "아빠랑"·"형이랑"·"동생이는"은 키워드 원형(아빠가·형이·동생이)의 활용형) / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

### #자존감
- 문장: "자꾸 내가 부족한 것 같아서 자신감이 없어지는데, 나 자신을 어떻게 사랑해줘야 할지 모르겠어요"
- 감지: 축1=자존감(부모님 모드, "내가 부족한 것 같아"·"자신감"·"나 자신을") / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

## 보강 예시 — 축2·축3 키워드 하이라이트

위 6개는 해시태그(=축1)를 보여주려고 축2·축3을 기본값으로 고정했다. 라이브러리 카드가 축2·축3 하이라이트도 렌더링하려면 그 값이 "키워드로 감지된" 사례가 최소 하나씩 있어야 해서, 기본값이 아닌 조합만 추가한다.

### 축2=완전 공감형 (#인간관계 보강)
- 문장: "친구가 나한테 심하게 화를 내서 마음이 너무 힘든데, 판단하지 말고 그냥 들어만 줘. 위로만 해줬으면 좋겠어"
- 감지: 축1=인간관계(친구 상담 모드, "친구가") / 축2=완전 공감형("판단하지 말고"·"그냥 들어만 줘"·"위로만 해줬으면") / 축3=기본값(우, 직접 조언 제시)

### 축2=직설·해결형 (#진로 보강)
- 문장: "이직을 고민 중인데 쓴소리 해도 되니까 팩트로 말해줘, 지금 내 상황이 객관적으로 뭐가 문제인지 알고 싶어"
- 감지: 축1=진로(진로 선생님 모드, "이직") / 축2=직설·해결형("쓴소리 해도 되니까"·"팩트로 말해줘"·"객관적으로 뭐가 문제인지") / 축3=기본값(우, 직접 조언 제시)

### 축3=좌, 질문으로 유도 (#자존감 보강)
- 문장: "자존감이 낮아진 것 같은데 답을 바로 주지 말고 같이 생각해봐줘, 질문 좀 던져줘"
- 감지: 축1=자존감(부모님 모드, "자존감") / 축2=기본값(균형형) / 축3=좌, 질문으로 유도("같이 생각해봐줘"·"질문 좀 던져줘")

### 축1=복수 키워드 동시 감지 → 우선순위 계산으로 단일 채택 (#연애 + #자존감 보강)
- 문장: "남자친구랑 헤어지고 나니까 내가 너무 부족한 사람 같아서 자신감이 다 없어졌어"
- 감지: 축1 후보 = 연애(연애고수 모드, "남자친구"·"헤어지고") + 자존감(부모님 모드, "내가 너무 부족한 사람 같아"·"자신감") 동시 등장 → `solution1.md`의 우선순위 계산(연령대 미상이면 4단계 생략, 최근성 가중치는 두 후보 모두 마지막 문장에 있어 동률, 기본 점수도 각 1회로 동률) 적용 시 동점 → 페르소나를 단정하지 않고 "지금 이별 얘기랑 자존감 얘기가 같이 나왔는데, 어느 쪽에 더 집중해서 얘기해볼까?" 같은 되묻기로 처리 / 축2=기본값(균형형) / 축3=기본값(우, 직접 조언 제시)

## 남은 메모
- 원본 6개 예시는 축2(스타일)·축3(개입방식)이 기본값 그대로 — 자연스러운 주제 문장 위주로 작성해서 억지로 다른 조합을 끼워넣지 않음. 기본값이 아닌 축2·축3 키워드 하이라이트가 필요해서 위 "보강 예시"를 별도로 추가함(균형형·우쪽은 이미 원본 6개가 기본값으로 커버).
- schemas/개인상담.md 축1은 한 문장에서 키워드가 여러 개 감지될 수 있고, 최종적으로는 `draft/docs-low/docs-hibro/solution1.md`의 우선순위 계산으로 페르소나 하나만 채택(동점이면 되묻기)한다 — 이를 보여주는 사례를 위 "축1=복수 키워드 동시 감지" 보강 예시로 추가함.
- "가족" 예시의 아빠랑·형이랑·동생이는은 schemas/개인상담.md 축1 키워드가 어근(아빠·형·동생) + startsWith 매칭 방식으로 확정되면서 조사가 붙은 활용형도 정상 감지된다(더 이상 "구현 시 확인 필요" 아님).
