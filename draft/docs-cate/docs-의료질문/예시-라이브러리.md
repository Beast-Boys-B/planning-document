# 프롬프트 라이브러리 예시 — 의료질문

> 이 문서는 F-공23(팀 큐레이션 프롬프트 라이브러리)의 실제 콘텐츠다. 담당자(우석민)가 직접 작성한 예시로, planning-partner 인터뷰 양식([?]/[제안])은 적용하지 않는다.
> 페이지1의 해시태그 칩(카테고리 선택 시 뜨는 태그, 클릭하면 입력창에 문장이 채워짐)과, 프롬프트 라이브러리 화면의 정적 스냅샷(원본/정제 비교 + 축별 색상 하이라이트, Page2와 동일한 레이아웃이되 인터랙티브하지 않은 read-only 형태)이 모두 이 내용을 기반으로 한다.
>
> 해시태그 선정 기준: (1) 어느 축이 어떻게 반영되는지 명확히 보여줄 수 있을 것, (2) 이 카테고리에서 실제로 자주 나올 법한 흔한 주제일 것.

## 해시태그 목록
#소화기 · #호흡기 · #피부 · #수면 · #만성질환관리 · #건강검진

## 예시 (해시태그별)

### #소화기
- 문장: "요즘 계속 속이 더부룩하고 소화가 안 돼서, 이게 무슨 문제인지 궁금해요."
- 감지: 목적=좌(증상·질병 정보 알아보기, "무슨 문제인지") / 대상=기본값(본인, 주어 없음) / 증상성격=우(오래된·만성, "계속")

### #호흡기
- 문장: "어제부터 갑자기 기침이 심하고 목이 아파요. 위험한 건 아닌지 걱정돼요."
- 감지: 목적=좌(증상·질병 정보 알아보기, "위험한 건 아닌지") / 대상=기본값(본인) / 증상성격=좌(갑자기 생긴 증상, "어제부터"·"갑자기")

### #피부
- 문장: "얼굴에 오래전부터 좁쌀 여드름이 안 없어지는데, 어떤 병일까요?"
- 감지: 목적=좌(증상·질병 정보 알아보기, "어떤 병일까요") / 대상=기본값(본인) / 증상성격=우(오래된·만성, "오래전부터")

### #수면
- 문장: "며칠째 계속 밤에 잠을 설치는데, 병원 가면 뭐라고 말해야 할지 모르겠어요."
- 감지: 목적=우(병원 가기 전 문진 준비하기, "병원 가면 뭐라고 말해야") / 대상=기본값(본인) / 증상성격=우(오래된·만성, "며칠째"·"계속")

### #만성질환관리
- 문장: "저희 어머니가 몇 년째 혈압 때문에 고생하시는데, 이 정도면 괜찮은 건지 궁금해요."
- 감지: 목적=좌(증상·질병 정보 알아보기, "이 정도면 괜찮은 건지") / 대상=우(가족/보호 대상자, "어머니가") / 증상성격=우(오래된·만성, "몇 년째")

### #건강검진
- 문장: "다음 주에 건강검진 받으러 가는데, 어떤 걸 미리 준비하면 좋을까요?"
- 감지: 목적=우(병원 가기 전 문진 준비하기, "검사받으러 가는데"류) / 대상=기본값(본인) / 증상성격=기본값(갑자기 생긴 증상 — 예방적 건강검진이라 증상 자체가 없는 상황에서 이 축이 기본값으로 빠지는 걸 보여주는 사례)

## 남은 메모
- 축2(대상)가 "가족" 쪽인 예시는 #만성질환관리 1개뿐 — 의도적으로 자연스러운 주제 선정을 우선했고, 억지로 비중을 맞추지 않음(팀 확인).
- 실제 화면 반영(해시태그 칩 UI, 라이브러리 정적 스냅샷 컴포넌트)은 피그마 단계에서 진행.
