## 화면 구성 (2페이지 정보구조로 재변경) — 팀(프로젝트 리드) 확정

**[구조 변경, 피그마 Make 프로토타입 검토 후 확정]** 기존에 확정했던 3페이지 구조(페이지1/페이지2/페이지3) 중 **페이지2(비교·조정)와 페이지3(완료)를 하나의 화면으로 통합**하기로 팀이 재확정했다. 이제 화면은 총 2개다: **페이지1(시작)**, **페이지2(비교·조정·완료 통합)**. (랜딩/페이지0은 화면 앞단이라 별개로 아래 표에서 계속 다룸.) 아래는 각 페이지에 어떤 F-공(또는 카테고리 전용 F) 항목이 대응하는지 매핑한 표다 — 통합에 따라 기존 F-공17("다음"→페이지3)과 F-공6("뒤로"→페이지2, 재조정 복귀)은 폐기됐다(아래 「기능」 표의 해당 행에 취소선으로 표시).
