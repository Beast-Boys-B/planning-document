#이메일
**거래처**에 프로젝트 **진행 상황을 공유**하는 **이메일**을 써줘.
목적: 정보 전달·보고 / 대상: 상급자·외부인 / 문서 유형: 간단한 형식

#보고서
**본부장**에게 이번 달 영업 **결과를 보고**할 **보고서**를 **체계적으로** 작성해줘.
목적: 정보 전달·보고 / 대상: 상급자·외부인 / 문서 유형: 체계적 형식
---

#자기소개서
**회사**에 제출할 자기소개서를 작성해줘. 입사 기회를 얻을 수 있도록 내 경험과 강점을 **상세하게** 정리해주고 오늘 완성하고 싶어.
목적: 기본값(정보 전달·보고) / 대상: 기본값(상급자·외부인) / 문서 유형: 체계적 형식
---

#에세이
**같은 팀 동료**들에게 내 생각을 **공유**할 에세이를 **문서** 형태로 작성해줘. 시간 있을 때 읽을 수 있게 너무 딱딱하지 않았으면 좋겠어.
목적: 정보 전달·보고 / 대상: 동료·팀원 / 문서 유형: 체계적 형식
---

#SNS글
**우리 팀** 프로젝트가 **완료**됐다는 내용을 SNS에 올리려고 해. **한두 줄**로 **간단히** 작성해줘. 지금 당장 올릴 거야.
목적: 정보 전달·보고 / 대상: 동료·팀원 / 문서 유형: 간단한 형식
---

#기획서
**팀장**에게 신규 프로젝트 **승인을 요청**할 **기획서**를 **상세하게** 작성해줘. 2시간 이내에 제출해야 해.
목적: 요청·승인 / 대상: 상급자·외부인 / 문서 유형: 체계적 형식
