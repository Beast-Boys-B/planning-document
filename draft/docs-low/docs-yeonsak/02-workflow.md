## 흐름
기본: S1 → S2 → S3 → S4
분기:
- S1에서 카테고리를 잘못 선택했다고 판단하면 → S1에서 다른 카테고리로 재선택
- S2에서 자연어 입력 후 → S3으로 이동 (분기 없음, 순서대로)
- S3에서 자동 분석된 옵션이 적절하면 → 수정 없이 S4로 이동
- S3에서 자동 분석된 옵션이 잘못되었거나 부족하면 → S3에서 직접 수정·추가한 후 S4로 이동
- S3 확인 과정에서 처음 선택한 카테고리 자체가 잘못되었다고 판단하면 → S1로 돌아가 카테고리를 다시 선택
- S4에서 생성된 프롬프트가 적절하면 → 복사 후 서비스 이용 종료
- S4에서 생성된 프롬프트를 보고 조건을 바꾸고 싶다면 → S3으로 돌아가 옵션을 수정한 뒤 다시 생성
