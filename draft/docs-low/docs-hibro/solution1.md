# 부록A. 개인상담 — 축1 다중 주제 감지 시 우선순위 공식

> 카테고리명: 개인상담
> 관련 문서: 03-requirements.md (R-상담9), 05-policies.md (P-상담5)
> 목적: 한 메시지에 두 개 이상의 상담 주제 키워드(연애/인간관계/학업/진로/가족/자존감)가 동시에 등장할 때, 축1(상담 주제별 페르소나)을 어떤 것으로 최종 채택할지 결정하는 계산 규칙

---

## 계산 순서

### 1단계 — 연령대 추정
아래와 같은 명시적 신호로 사용자의 연령대를 판별한다.
- 예: "고3", "대학생", "취준생", "저 OO살", "직장 N년차", "애 엄마·아빠"
- 신호가 없으면 "연령 미상" 상태로 두고, 4단계(연령대 가중치)는 적용하지 않는다.

### 2단계 — 주제별 기본 점수
메시지 안에서 각 주제 키워드가 등장한 횟수 1회당 **+1점**을 부여한다.

### 3단계 — 최근성 가중치
메시지를 문장 단위로 나눴을 때, **가장 마지막 문장**에 등장한 주제에 **+2점**을 부여한다.

### 4단계 — 연령대 가중치
연령대가 파악된 경우에만 아래 표의 값을 더한다.

| 연령대 | 연애 | 인간관계 | 학업 | 진로 | 가족 | 자존감 |
|---|---|---|---|---|---|---|
| 10대 | +1 | +2 | +3 | 0 | 0 | +1 |
| 20대 | +3 | +1 | 0 | +2 | 0 | +1 |
| 30대 | +1 | 0 | 0 | +3 | +1 | +1 |
| 40대 | 0 | +1 | 0 | +1 | +3 | +1 |
| 50대 이상 | 0 | +1 | 0 | 0 | +2 | +3 |

### 5단계 — 최종 점수 계산 및 채택
```
최종 점수 = 기본 점수(2단계) + 최근성 가중치(3단계) + 연령대 가중치(4단계)
```
- 최고점 주제를 축1의 최종 페르소나로 채택한다.
- 동점일 경우, 최근성(3단계에서 가산을 받았는지 여부)이 높은 쪽을 우선한다.
- 그래도 동점이면 페르소나를 단정하지 않고 사용자에게 되묻는다.
  > 예시 문구: "지금 OO 얘기랑 XX 얘기가 같이 나왔는데, 어느 쪽에 더 집중해서 얘기해볼까?"

## 예시 계산

**입력 문장**: "고3인데 시험 스트레스로 남자친구랑도 자꾸 싸워"

| 단계 | 학업 | 연애 |
|---|---|---|
| 1. 연령대 추정 | "고3" → 10대로 판별 | 동일 |
| 2. 기본 점수 | "시험" 1회 → +1 | "남자친구" 1회 → +1 |
| 3. 최근성 가중치 | 마지막 문장(전체가 한 문장)에 둘 다 등장 → 둘 다 +2 | 둘 다 +2 |
| 4. 연령대 가중치(10대) | +3 | +1 |
| **최종 점수** | **1+2+3 = 6** | **1+2+1 = 4** |

→ 학업이 더 높으므로 축1 페르소나는 "친한 선생님 모드"로 채택된다.
